# Contributing

Thanks for improving `awesome-openclaw-hardware`.

## What Belongs Here

This repo is for hardware directions that matter to OpenClaw builders, including:

- smart glasses
- voice devices
- edge AI boards
- physical interaction experiments
- supporting setup resources

## Submission Rules

- Keep entries relevant to OpenClaw or OpenClaw-like device workflows.
- Prefer practical, buildable, or clearly informative resources.
- Add one short English note for every entry.
- Avoid hype-only product pages with no useful context.

## Good Additions

- real device demos
- integration guides
- community experiments
- hardware-specific setup notes
- interface design references for agent hardware
